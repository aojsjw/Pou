# IMMINENT RGB Panel

A polished RGB neon edition of the IMMINENT management panel, prepared for GitHub.

## Highlights

- Full RGB neon visual theme
- Responsive modern dashboard
- Animated RGB borders, titles, and glow effects
- Subscription links exposed in a clean Marzban-style format
- Persian/English UI support
- Ready for GitHub, Railway, and Render deployment

## Run locally

```bash
pip install -r requirements.txt
python main.py
```

Then open `http://127.0.0.1:8000`.

## Deploy

The repository includes `Procfile` and `render.yaml` for easy deployment.

## Version

`2.0.0-rgb`
